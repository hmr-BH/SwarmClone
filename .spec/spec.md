# 需求规格说明

## 1. 项目概述

### 1.1 项目背景
本项目是一个多语言混合开发的虚拟形象控制系统,旨在为VRChat等虚拟社交平台提供智能化的虚拟形象驱动能力。系统需要整合多种技术栈,实现从语音识别、动作控制到3D模型渲染的完整链路。

### 1.2 项目目标
- 构建一个模块化、可扩展的虚拟形象控制系统
- 支持多种输入方式(语音、键盘、视觉捕获)
- 实现与VRChat的无缝对接
- 提供友好的Web控制面板
- 支持一键部署和快速配置

### 1.3 系统范围
系统包含以下核心功能:
- CLI命令行工具(用于一键部署和配置管理)
- 核心业务逻辑处理(语音识别、动作映射、状态管理)
- 3D模型显示与渲染(Live2D/VRM模型支持)
- VRChat对接与动作控制
- Web控制面板(配置管理、状态监控)
- 独立服务模块(ASR、视觉捕获、键盘操作等)

### 1.4 排除范围
系统不包含:
- VRChat客户端本身的开发
- 3D模型的建模和制作工具
- 语音识别引擎的核心算法开发(使用现有ASR服务)
- 复杂的AI对话生成功能

## 4. 约束条件

### 4.1 技术约束

**技术栈要求**:
- CLI工具: 使用Rust开发,编译为原生可执行文件
- 核心业务逻辑: 使用Python开发,版本 ≥ 3.9
- 3D前端: 使用Godot引擎开发,版本 ≥ 4.0
- VRChat对接: 使用C#开发,基于VRChat SDK
- Web控制面板: 使用Vue.js开发,版本 ≥ 3.0

**目录结构约束**:
```
project/
├── cli/              # Rust CLI工具
├── core/             # Python核心业务逻辑
├── frontend/         # Godot 3D前端
├── panel/            # Vue.js Web控制面板
├── scripts/          # 快捷脚本
└── services/         # 独立服务模块
    ├── asr/          # ASR客户端
    ├── vision/       # 视觉捕获
    ├── vrchat/       # VRChat对接
    └── keyboard/     # 键盘操作
```

### 4.2 业务约束

**许可约束**:
- 所有代码遵循开源协议
- 使用的第三方库需兼容项目协议
- 不得包含商业授权的闭源组件

**资源约束**:
- 3D模型资源需用户自行提供
- ASR服务需用户自行部署或使用第三方服务
- VRChat账号需用户自行注册

## 5. 依赖关系

### 5.1 外部依赖

**运行时依赖**:
- Python 3.9+
- Node.js 16+
- Rust 1.70+
- Godot 4.0+

**第三方服务依赖**:
- ASR引擎(如Whisper、Azure Speech等)
- VRChat客户端
- 摄像头设备(可选)

**第三方库依赖**:
- Python: asyncio, pydantic, loguru等
- Rust: clap, tokio, serde等
- Vue.js: vue-router, pinia, element-plus等
- Godot: Live2D插件、VRM插件

### 5.2 内部依赖

**模块依赖关系**:
- CLI工具依赖所有其他模块的配置接口
- 核心模块依赖所有服务模块
- 前端模块依赖核心模块的动作指令
- 控制面板依赖核心模块的状态接口
- 各服务模块独立运行,通过消息队列或RPC通信

**数据流依赖**:
- ASR服务 → 核心模块 → VRChat模块
- 视觉服务 → 核心模块 → 前端模块
- 键盘服务 → 核心模块
- 控制面板 ↔ 核心模块(双向)

## 6. 术语表

**ASR (Automatic Speech Recognition)**
: 自动语音识别,将语音转换为文本的技术。

**VRM**
: Virtual Reality Model,一种用于虚拟现实的3D模型格式,基于glTF。

**Live2D**
: 一种2D模型动画技术,通过参数控制实现类似3D的动态效果。

**VRChat**
: 一个虚拟现实社交平台,用户可以使用自定义虚拟形象进行交互。

**OSC (Open Sound Control)**
: 一种用于实时通信的协议,常用于VRChat参数控制。

**动作映射**
: 将输入指令(语音、键盘等)转换为3D模型动作参数的规则配置。

**表情参数**
: 控制模型面部表情的数值参数,如眨眼、微笑等。

**动作参数**
: 控制模型身体动作的数值参数,如挥手、点头等。
